# Genome-and-Transcriptome-assembly
Training into the genome assembly of a dataset from Arabidopsis using three different assemblers, followed by its evaluation. In addition, learning transcriptome assembly from an RNA-Seq dataset. 
The database Had-6b represents one of the Arabidopsis species of the African lineage, adapted from the publication: Qichao Lian et al. A pan-genome of 69 Arabidopsis thaliana accessions reveals a conserved genome structure throughout the global species range. Nature Genetics. 2024;56:982-991. Available from: https://www.nature.com/articles/s41588-024-01715-9
